# MySQL 使用规范

## 建表规范

每张表必须有自增主键 `id BIGINT UNSIGNED`，并且必须包含 `created_at` 和 `updated_at` 两个时间字段。
字符集统一使用 `utf8mb4`；禁止使用外键约束，表之间的关联关系由应用层保证。

## 慢查询与索引

执行时间超过 1 秒的 SQL 会被记为慢查询，每天汇总后发送给对应服务负责人。
单张表的索引数量不超过 5 个；禁止使用 `SELECT *`，必须显式写出需要的字段。

## 数据库变更流程

所有 DDL 变更都必须通过工单系统提交，并经过 DBA 审核后执行。
超过 1000 万行的大表变更必须使用 gh-ost 做在线变更，避免长时间锁表。
