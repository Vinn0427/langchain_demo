# 发布流程

## 发布平台与发布窗口

团队所有服务通过内部发布平台「白鹭」（Egret）上线。
常规发布窗口为每周二、周四的 14:00–17:00；每周五以及法定节假日前一天封网，禁止常规发布，紧急修复需要部门负责人审批。

## 灰度发布

新版本必须按 1% → 10% → 50% → 100% 四个阶段灰度放量，每个阶段至少观察 30 分钟。
放量期间重点关注两个核心指标：错误率不得超过 0.5%，P99 延迟相比上一版本上涨不得超过 20%。任一指标超标都要暂停放量。

## 回滚规范

线上发现问题后，值班负责人必须在 5 分钟内做出是否回滚的决定，原则是"先止血、再定位"。
回滚命令为 `egret rollback --app <应用名> --to <版本号>`，回滚完成后需要在发布单里补充原因说明。
